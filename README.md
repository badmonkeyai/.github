# Bad Monkey organization profile

The public GitHub organization home page is authored in [profile/README.md](profile/README.md).
The root README describes this repository; GitHub displays the profile README on
[github.com/badmonkeyai](https://github.com/badmonkeyai).

## Publish

1. Keep this repository named `.github` and public.
2. Review the profile and commit the files on the default branch (`main`).
3. Push the commit. GitHub displays `profile/README.md` on the organization's public Overview.

GitHub's instructions: [Customizing your organization's profile](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile).

The banner is an unchanged copy of the existing Bad Monkey office illustration
from `web/site-drafts/new-company-site/assets/img/banner-office.jpg` in the
AgentSpaces workspace (also present in `web/site-template/img/`). It is stored in
this repository so the profile does not depend on draft-site paths. Its absolute
raw GitHub URL is deliberate: it works on both the repository and organization pages.

The profile uses GitHub Flavored Markdown and supported HTML, with no custom CSS,
JavaScript, external fonts or generated badge services. GitHub supplies responsive
layout and light/dark themes; the banner keeps the site's existing palette.

## Suggested pins

Organization owners can choose up to six public pins. Suggested starting set:

- `AgentSpaces` — the core and the primary entry point.
- `agentspaces-groovy` — the notebook console.
- `agentspaces-python` — Python developers.
- `agentspaces-typescript` — TypeScript developers.
- `agentspaces-example-apps` — complete applications.
- `agentspaces-harness` — coding-agent integrations.

Pins are organization settings and are not configured by this README.
